# Aplicacion Adaptativa y Sensores

Aplicacion Flutter con interfaz adaptativa, consumo de API REST y lectura de hardware en tiempo real.

## Funcionalidades
- Layout adaptativo: NavigationBar en pantallas angostas y NavigationRail en pantallas anchas.
- API REST: Consumo de productos desde DummyJSON adaptados a ListView o GridView.
- Sensores en tiempo real: Monitoreo de porcentaje/carga de bateria y acelerometro (ejes X, Y, Z).

## Como ejecutar
1. Obtener dependencias:
   flutter pub get

2. Ejecutar app:
   flutter run
